# Long Assessment 1 LaTeX report skeleton

The template is intentionally broad. Reorder, combine, or remove subsections to
fit the scientific argument for the selected material. It is not a scoring
rubric or a requirement to fill every placeholder mechanically.

## Build

From this directory:

```bash
latexmk -pdf long-assessment-1-report-template.tex
```

The repository includes the compiled PDF so students can inspect the skeleton
without a local TeX installation. Delete every red `TODO`, replace placeholder
figures, complete citations, and update the student metadata before submission.

Keep generated figures in `figures/` at repository root or adjust
`\\graphicspath` in the template.
